Headers de seguridad

Spring Security — configuracion segura vs sin headers.

ANTES — sin headers

headers.disable() en la cadena de seguridad.

DESPUÉS — seguro

CSP, X-Frame-Options, HSTS, CSRF, sesion STATELESS.

Ver headers reales

curl -i http://localhost:8191/api/insecure/check
curl -i http://localhost:8191/api/secure/check

HSTS solo aparece en respuestas HTTPS. En local HTTP veras el resto de headers.
